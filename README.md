# Rahul & Soumi | Wedding Reception Invitation

A wedding reception invitation site for Rahul Mukherjee and Soumi Ghosh.

## Development

```sh
bun install
bun run dev
```

Other useful scripts:

```sh
bun run test    # run tests
bun run lint    # run eslint
bun run build   # production build
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
